# GenZ Store

GenZ Store is an e-commerce platform with a React + TypeScript storefront and Spring Boot backend.

## Project
- Frontend: React, TypeScript, Vite
- Backend: Spring Boot, Java 21
- Database: PostgreSQL
- Authentication: JWT + Spring Security
- Payments: COD and Razorpay foundation
- AI: AI Stylist foundation
